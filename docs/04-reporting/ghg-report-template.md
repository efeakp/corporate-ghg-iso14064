# GHG report template

*ISO 14064-1:2018, clause 9*

Copy this outline for each year's report. Clause 9.3 of ISO 14064-1 lists
the required and recommended content in full. Use it as the final checklist.

## 1. About the organisation

- Description of the reporting organisation
- The person responsible for the report
- The reporting period
- Intended users and how the report will be published

## 2. Boundaries

- Organisational boundary and consolidation approach
- Reporting boundary, with the criteria used to judge significant indirect emissions
- Excluded sources, with reasons

| 6. Other | | |
| **Total** (state which Category 2 figure is used) | | |

- Results broken down by gas, and by facility or entity where relevant
- Biogenic CO₂ emissions and removals, reported separately
- GHG removals, if any

## 4. Methods

- Quantification methods, and changes since last year
- Emission factors and GWPs used, with sources
- Description of the uncertainty assessment, and its results

## 5. Base year and trends

- Base year and base-year emissions
- Any recalculation, and the reason for it
- Comparison over time

## 6. Reductions

- GHG reduction initiatives, and their effect, if quantified (clause 7)
- Use of offsets or contractual instruments, disclosed separately

## 7. Assurance

- Whether the report was verified, by whom, and the level of assurance
- A statement that the report was prepared in accordance with ISO 14064-1:2018
