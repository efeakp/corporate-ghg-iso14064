# Verification readiness checklist

Before the verifier arrives, confirm that each item exists and that its link
works.

## Inventory design

- [ ] Organisational boundary and consolidation approach, with rationale
- [ ] Boundary register: entities, ownership, control, inclusion
- [ ] Source register for all six categories
- [ ] Significance criteria and the assessment record
- [ ] Base year, base-year inventory and recalculation policy

## Quantification

- [ ] Activity data for each source, every row linked to evidence
- [ ] Emission-factor register with sources and versions
- [ ] Calculation files that reproduce the reported totals exactly
- [ ] Estimates flagged, with their methods
- [ ] Uncertainty assessment

## Controls

- [ ] Inventory management plan, with roles
- [ ] Completed QA/QC checklist
- [ ] Internal review record
- [ ] Methodology decision log
- [ ] Prior-year findings: every one closed or explained

## Outputs

- [ ] Draft GHG report (clause 9 content)
- [ ] GHG statement signed by the responsible person
- [ ] Git tag or commit hash of the version submitted for verification

## Logistics

- [ ] Data owners available for interviews
- [ ] Site visit schedule agreed (where applicable)
- [ ] Verifier has read-only access to the evidence store
